## [1.0.0] - 2025-01-24

### Added
- Initial release of PhantomCortex
- Core threat collection engine with 17+ RSS feeds
- Offline AI translation using Argos Translate
- Email alerting system with HTML templates
- Monthly report generation in Word format
- Configurable severity classification
- Technology-specific threat filtering
- Intelligent threat deduplication
- Comprehensive documentation
- Unit tests for core functionality
- Docker support with docker-compose
- GitHub Actions CI/CD pipelines
- MIT License

### Features
- **Collection**: Automated threat gathering from government, vendor, and community sources
- **Translation**: Offline translation (English → Spanish) with no API keys required
- **Alerting**: Professional HTML email alerts with severity-based filtering
- **Reporting**: Executive-ready monthly reports with charts and analysis
- **Monitoring**: Track 100+ technologies out of the box
- **Automation**: Cron-ready scripts for daily/monthly operations
- **Extensible**: Modular architecture for easy customization
